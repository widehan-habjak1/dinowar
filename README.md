# DINO : LAST
React + TypeScript + Vite / Node.js 실시간 1:1 공룡 수집·소환 전투.

## 실행
```sh
npm install
npm run dev
```
프론트(Vite)와 게임 서버(기본 3001)를 함께 시작합니다. 프론트는 Vite가 출력하는 URL로 접속하세요. 다른 기기에서는 같은 Wi-Fi의 Network URL을 사용합니다. localhost는 각 기기의 자신을 뜻하므로 친구에게 Network URL을 전달하세요.

```sh
npm run build
npm test
npm run server
```
`npm test`는 엔진 규칙과 실제 HTTP/SSE 두 클라이언트의 입장·준비·동기화·퇴장을 검증합니다.

## 게임 규칙
- 방장이 6자리 코드를 생성하고 한 명이 코드로 입장합니다. 양쪽이 준비하면 시작합니다.
- 30초간 수풀 6곳에 랜덤 공룡이 약 1.25초 동안 나타납니다. 서버가 유효한 클릭만 인정하고 중복 클릭을 차단합니다.
- 잡은 공룡 한 마리마다 한 번 출격할 수 있습니다. 같은 종을 여러 번 잡으면 그만큼 소환할 수 있습니다. 기본 도감에 보유한 공룡을 반입하지 않고 매 경기 새로 모읍니다.
- 고인돌 체력은 1000. 보급 80으로 시작해 초당 12 충전, 최대 160입니다. 공룡별 보급 30~70을 소비합니다. 최대 한쪽 24마리까지 전장에 배치됩니다.
- 소환한 공룡은 자동 전진하고 근처 상대 공룡을 공격한 뒤 고인돌을 공격합니다. 서버가 양쪽 피해를 동시에 계산합니다. 전투 제한 3분, 동시 파괴/시간 초과/모든 공룡 소진은 무승부입니다.
- 패배하면 그 라운드에서 잡은 공룡의 출격 목록이 지워집니다. 해당 종은 브라우저 보유 목록에서도 제거되며 탐험으로 재수집 가능합니다. 무승부에는 멸종을 적용하지 않습니다.
- 나가기/항복은 패배, 연결이 20초 넘게 끊겨도 패배입니다. 같은 탭 새로고침은 세션을 복원합니다.
- 혼자 AI 연습과 본부의 30초 단독 탐험도 지원합니다. 단독 탐험은 수집 종료 후 도감에 저장됩니다.

## 에셋
기본 공룡 30종. `src/dinosaurs.ts`가 ID·이름 대응표입니다. 새 ID 24~29는 릴리엔스테르누스, 헤레라사우루스, 스타우리코사우루스, 플라테오사우루스, 에오랍토르, 코엘로피시스 순서입니다.
`public/dinosaurs/{id}.png`, `public/scenes/battle.png`를 사용합니다.

## Vercel 프론트 배포
Framework Vite / build `npm run build` / output `dist`.
게임 서버는 지속 실행되는 Node.js 호스팅에 별도로 실행해야 합니다. Vercel 정적 프론트 배포만으로 멀티플레이 서버는 동작하지 않습니다.
- 서버: `npm install` 이후 `npm run server`, `PORT`는 호스팅 제공 값을 사용합니다.
- 서버 `ALLOWED_ORIGINS=https://your-app.vercel.app` (여러 주소는 쉼표로 구분).
- Vercel 빌드 환경 `VITE_GAME_SERVER_URL=https://your-game-server.example`.
- 서버의 `/api/events` SSE 연결을 프록시가 버퍼링하지 않도록 설정하세요.
- `/api/health`로 서버 정상 동작을 확인할 수 있습니다.

현재 서버는 메모리 기반 단일 인스턴스입니다. 재시작하면 방이 사라지고 30분 지난 방은 정리됩니다. 계정/영구 서버 저장은 없으며 도감·승리는 브라우저에 보관합니다. 방 토큰 기반으로 행동을 구분하고 실제 승패·수집·전투 판정은 서버가 수행합니다. 공개 서비스 확장에는 DB와 재접속/매칭 저장소가 필요합니다.

## 웹게임 UI
전체 화면형 숲 테마 로비, 상단 플레이어/에너지 HUD, 하단 고정 게임 메뉴, 지역 선택과 즉시 탐험, 공룡 동료 카드, 수집 도감 필터/상세, 게임 방법 및 브라우저 전체 화면 버튼을 제공합니다. 수집 기록은 기존 저장 키를 유지합니다. PVP 화면을 벗어나도 Arena는 마운트를 유지해 게임 연결이 보존됩니다. 화면 크기와 높이에 따른 반응형 레이아웃과 모션 감소 설정을 지원합니다.

모에화 기능은 제거되었으며 모든 게임 화면은 기본 공룡 그림만 사용합니다.

### 횡스크롤 전투 연출
PVP는 제공된 전장 배경 위에서 고인돌 양쪽에 공룡을 소환하는 방식입니다. 공룡은 자동으로 전진하다 상대를 만나면 멈춰 공격하고, 상대를 쓰러뜨리면 다시 전진해 고인돌을 공격합니다. 걷기/공격/피격/퇴장과 고인돌 피격 효과는 서버 전투 상태에 연결됩니다. 공룡 HP 수치·게이지와 화면 상단의 큰 기지 HP 패널은 제거했으며 고인돌 위 작은 내구도 표시만 유지합니다. 서버 내부 체력은 충돌·생존·승패 계산에 사용됩니다.
